🔧 TECHNICAL DETAILS:
════════════════════

  Algorithm: POPS with Inequality Constraints
  ─────────────────────────────────────────
  • Quadratic programming via OSQP solver
  • Sparse matrix format for efficiency
  • Per-point independent optimization (parallel-ready)
  • Each ensemble member passes through its training point
  • Constraints enforced via inequality bounds

  Solver Configuration:
  • eps_abs = 1e-4 (absolute tolerance)
  • eps_rel = 1e-4 (relative tolerance)
  • max_iter = 10000 (maximum iterations)
  • Typical solve: 10-50 iterations per point

  Language: Julia 1.x
  Dependencies: OSQP, SparseArrays, LinearAlgebra, Statistics, CairoMakie

🎯 WHEN TO USE CONSTRAINTS:
═══════════════════════════

  ✓ DO USE when:
    • Model is severely misspecified (oscillatory data vs polynomial)
    • Extrapolation/generalization is important
    • Physical bounds are known (e.g., y ≥ 0, prob ∈ [0,1])
    • Smoothness/monotonicity is expected
    • Generalization error matters more than training fit
    • You have limited extrapolation data coverage

  ✗ DON'T USE when:
    • Model is well-specified (constraints won't help)
    • Data naturally respects constraints (redundant)
    • Training fit error is paramount
    • Constraint violations are physically impossible
    • You need maximum training accuracy for sensitivity analysis

🎓 KEY LEARNINGS:
═════════════════

1. POPS creates an ensemble where each member passes through ONE data point
2. Constraints can improve generalization by 14-29% in extrapolation
3. Trade-off: Small training fit increase (~18%) for large generalization gain
4. CLASSIC BIAS-VARIANCE TRADE-OFF demonstrated in Example 3
5. Constraints most powerful for severely misspecified models
6. OSQP solver reliable and efficient for constrained POPS updates
